⚡ Features

💻 Multi-Language Workbench: Full syntax highlighting, line numbers, themes, and auto-indent for Java, Python, SQL, HTML, CSS, JavaScript, JSON, and Markdown.

🐙 Full GitHub Repository Sync & Editing:

Connect with GitHub Personal Access Token (PAT).

Search and select from any of your public or private repositories.

Load repository file trees, branch switching (main, dev, etc.).

Edit code and Commit & Push changes directly to GitHub with custom commit messages.

Create and delete files remotely on GitHub.

🐍 In-Browser Python Execution (Pyodide): Run Python scripts directly using WebAssembly with sys.stdout streaming output.

🤖 Configuring Gemini AI Assistant & GitHub Token

GitHub Connection:

Click the GitHub button in the header bar.

Enter your GitHub Personal Access Token (PAT) with repo scopes.

Pick any repository from your account or type owner/repository.

Load the repository files directly into the workspace tree.

Edit files and click Commit & Push to commit changes directly back to your GitHub repository!

Nova AI Assistant:

Open the Nova AI panel from the right sidebar in the IDE.

Use quick action buttons like "Explain Code", "Fix Bugs", or "Refactor" to interact with the current active file code.
