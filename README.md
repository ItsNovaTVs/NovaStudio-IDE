## ⚡ Key Features

- 💻 **Multi-Language Workbench**: Crisp Devicon typography & syntax highlighting for **C, C++, Go, Rust, Kotlin, TypeScript, Python, Java, SQL, PHP, Ruby, Shell/Bash, HTML, CSS, JavaScript, JSON, YAML, Swift, and R**.
- 🎨 **Fixed Language Icons**: Uses standard Devicon CDNs so language icons for Python, C, C++, Rust, Go, Kotlin, and TypeScript display properly without missing box glyphs.
- 🐙 **Full GitHub Repository Sync & Editing**:
  - Connect with GitHub Personal Access Token (PAT).
  - Search and select from any public or private repository.
  - Load repository file trees, branch switching (`main`, `dev`, etc.).
  - Edit code and **Commit & Push** changes directly to GitHub with custom commit messages.
- 🤖 **100% Free AI Assistant**: Integrated code assistant for code explanations, bug fixing, refactoring, and unit test generation. **Requires NO paid Gemini subscriptions or API keys!**
- 🐍 **In-Browser Execution Engines**:
  - Python WASM Pyodide runtime.
  - AlaSQL query engine with interactive tabular grid view.
  - Web preview iframe sandbox for HTML, CSS, and JS.
  - Client-side execution simulators for C, C++, Go, Rust, Kotlin, Java, PHP, and Ruby.
- 📦 **Export & Local Storage**: Automatically saves workspace locally and exports project zip packages via JSZip.
